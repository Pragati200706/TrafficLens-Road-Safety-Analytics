# TrafficLens — Road Safety Analytics

A Streamlit dashboard for exploring aggregate Indian road-accident statistics from 2016–2019, with weather, violation and junction views.

## Run locally
Install requirements with `pip install -r requirements.txt`, then run `streamlit run app.py`.

Data source: Government of India OGD portal, https://www.data.gov.in/catalog/road-accidents-india-2019

Note: the supplied CSVs are aggregate tables, not individual incident records.
